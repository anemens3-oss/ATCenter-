# PROJECT 04 — ATCENTER (Body Repair Studio Redesign Concept)

Независимая демонстрационная концепция редизайна коммерческого сайта для московского центра кузовного ремонта **ATCenter** ([https://av-tt.ru/](https://av-tt.ru/)).

> **Дисклеймер:** Данный проект является независимым дизайн-концептом и не является официальным сайтом компании ATCenter. Все фактические данные о филиалах, услугах и фотографии выполненных кузовных работ взяты из открытых материалов официального сайта `av-tt.ru`.

---

## 1. Технологический стек (Pure Vanilla Stack)

Проект реализован строго без сторонних JS/CSS-библиотек и фреймворков:
- **HTML5** (`index.html`) — семантическая разметка, Open Graph, доступность с клавиатуры (`ARIA`, `role="tablist"`, `role="dialog"`).
- **CSS3** (`css/style.css`) — модульная система CSS Custom Properties, асимметричная редакционная сетка, адаптивность от `360px` до `1920px`, учёт `prefers-reduced-motion: reduce`.
- **Vanilla JavaScript ES6+** (`js/main.js`) — кастомная scroll-анимация (`requestAnimationFrame` + `IntersectionObserver`), фильтрация портфолио, собственный Lightbox с поддержкой клавиш `Escape` / `ArrowLeft` / `ArrowRight` и свайпов, интерактивный слайдер `До / После`.

```text
├── index.html          # Главная страница (все 9 секций)
├── css/
│   └── style.css       # Авторские стили в концепции Dark Automotive Cinematic
├── js/
│   ├── main.js         # Чистая логика и интерактивные контроллеры (Vanilla ES6+)
│   └── main.test.js    # Модульные тесты чистой логики (node:test)
├── assets/
│   └── images/         # Локальные изображения (относительные пути assets/images/...)
└── research.md         # Предпроектное исследование и проверенные факты о компании
```

## 2. Реализованные секции и функции

1. **SECTION 01 — HERO**: Полноэкранная студийная экспозиция с визуальным концептом Dodge Challenger SRT Hellcat, крупной типографикой, техническим регламентом и прямыми контактами двух московских филиалов.
2. **SCROLL CAR ANIMATION (`#scroll-showcase`)**: Sticky-сцена кинематографического разбора кузова в 4 этапа (01. Экспозиция → 02. Геометрия и стапель с векторной сеткой допусков → 03. Макро-план крыла и колористика → 04. Финальный студийный вид) с поддержкой как прокрутки, так и ручного переключения вкладок.
3. **SECTION 02 — PHILOSOPHY («Восстановление — это точность»)**: Подход мастерской к сохранению оригинальных деталей, 16+ лет опыта и реальные фотографии кузовного цеха ATCenter.
4. **SECTION 03 — SERVICES**: Асимметричный редакционный каталог 8 основных направлений (кузовной ремонт, локальная покраска, полная покраска, ремонт бамперов, удаление вмятин без покраски PDR, восстановление геометрии, стапельные работы, детейлинг и ремонт автостёкол).
5. **SECTION 04 — PAINT TECHNOLOGY**: Разбор компьютерной колористики, учёта естественного выцветания ЛКП, покраски переходом и работы герметичной покрасочной камеры.
6. **SECTION 05 — WORKS GALLERY**: Галерея реальных выполненных проектов с `https://av-tt.ru/galereya-rabot/` с фильтрацией по рубрикам и собственным многокадровым Lightbox.
7. **SECTION 06 — WHY ATCENTER**: 7 подтверждённых преимуществ техцентра в строгой архитектурной вёрстке.
8. **SECTION 07 — BEFORE / AFTER**: Интерактивный слайдер сравнения `До / После` на реальных парных фотографиях одних и тех же автомобилей (`Opel Astra GTC`, `Audi Q3`, `Кроссовер — бампер`, `KIA — капот`).
9. **SECTION 08 & 09 — CONTACTS & FOOTER**: Два филиала в Москве (Жулебино и Кожуховская) с прямыми кликабельными ссылками `tel:`, `mailto:`, WhatsApp, Telegram и маршрутами на картах.

## 3. Публикация на GitHub Pages и Cloudflare Pages

Все пути к стилям (`css/style.css`), скриптам (`js/main.js`) и изображениям (`assets/images/...`) являются **относительными**, поэтому проект работает без изменений как в корне домена, так и в подпапке репозитория (`https://username.github.io/repository-name/`).

### GitHub Pages
1. Загрузите файлы репозитория (`index.html`, `css/`, `js/`, `assets/`) в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите `Deploy from a branch`, укажите ветку `main` и папку `/ (root)`.

### Cloudflare Pages / Workers Static Assets
1. Подключите репозиторий в панели **Cloudflare Pages**.
2. Оставьте команду сборки пустой (или `npm run build` при использовании сборщика), директория публикации — `/` (или `dist`).
